#  EcoCampus

Plataforma web de reporte y seguimiento ambiental para campus universitarios. Permite a estudiantes reportar problemas ambientales (residuos, fugas de agua, etc.) y a administradores gestionar, dar seguimiento y resolver esos reportes desde un panel centralizado.

## Funcionalidades

- **Login diferenciado** por rol: Estudiante / Administrador, además de registro de nuevos usuarios.
- **Panel del Estudiante**
  - Reportar nuevos problemas ambientales (tipo, ubicación, descripción).
  - Consultar el historial y estado de sus propios reportes.
- **Panel de Administración General**
  - Estadísticas y métricas en tiempo real (total de reportes, pendientes, en proceso, solucionados).
  - Gráfico de reportes agrupados por estado.
  - Gráfico de tipos de problemas ambientales reportados.
  - Gestión global de incidentes: cambiar el estado de cada reporte (Pendiente / En proceso / Solucionado) y agregar comentarios para el estudiante.

## Tecnologías
